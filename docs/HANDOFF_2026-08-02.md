## Product architecture and non-negotiable invariants

Clozn is split into:

- a stdlib-only Python gateway and CLI;
- private C++ GGUF workers on random loopback ports;
- versioned JSON protocol/artifact contracts;
- a React 19/Vite/TypeScript Studio in `studio-frontend/`.

The Python gateway now runs in the managed supervisor process. C++ model workers remain
private subprocesses. The gateway is the only public endpoint.

Preserve these invariants:

- Runs are immutable. Repairs, experiments, replays, and branches create child runs.
- A request never silently falls back to another model.
- Persist requested model, resolved GGUF identity, template, worker identity/generation,
  adapter/settings, and applicable load events.
- “Delivered,” “measured effect,” “below the measurement floor,” “unavailable,” and
  “failed” are different states. Missing evidence is not a zero.
- Structural comparison is not causal attribution. Only an intervention or a
  deterministic evidence rule can support a causal/contributing-factor claim.
- Unknown schema and action versions fail closed or render as unknown.
- Product code stays Torch/Transformers-free. Heavy qualification work belongs in the
  lab boundary and returns validated, checksummed artifacts.
- Inspection endpoints do not eagerly launch expensive experiments. Expose explicit
  actions/jobs and persist the result.
- Preserve separate artifact-specific evidence unions in Studio. Do not flatten them
  into one universal enum merely for visual convenience.

Time Machine contracts/routes added in the current tree include:

- `clozn.time-machine-eligibility.v1`
- `clozn.time-machine-verification.v1`
- `clozn.time-machine-branch.v1`
- `GET /runs/<id>/time-machine`
- `POST /runs/<id>/time-machine/verify` with `{"turn": N}`
- `POST /runs/<id>/time-machine/branch` with `{"turn": N}`
- `POST /runs/<id>/time-machine/continue` with the closed
  `{"turn": N, "user": {"content": "..."}, "max_tokens": N}` request

The exact branch route hydrates a durable pin when present, otherwise captures the exact
source run, proves an unchanged control, plans a `none` execution fork at position zero,
and persists the child only after the exact control matches. Its receipt contains both
requested and source run IDs so historical proof provenance is not obscured.

The older `POST /runs/<id>/branch` route is intentionally structural transcript replay.
It may accept a changed question but is not exact KV continuation. Never relabel it as
exact.

The appended-turn route now restores the exact source turn's durable pin, validates that
the newly rendered transcript has the source token history as an exact prefix, sends only
the appended token IDs to the private worker, and persists an immutable child plus terminal
receipt atomically. It fails closed when the pin, source, runtime/tokenizer/template/adapter,
checkpoint, prefix proof, or worker capability is unavailable. Studio exposes this as a
third action, visibly separate from same-prompt exact replay and structural branching, and
includes per-turn pin preview/pin/unpin controls with restart-safe readiness.

## Why there are many JSON files

Do not delete JSON by category alone. The repository uses several fundamentally different
kinds:

- `clozn/schemas/defs/*.json` are source-controlled, versioned API/artifact contracts.
  They are product source and must remain.
- `tests/fixtures/schemas/<schema>/valid__*.json` and `invalid__*.json` prove each contract
  accepts and rejects the intended shapes. They are tests and must remain.
- `runs/experiments/*.json` are bounded live-smoke, lab, or audit evidence. They explain
  exactly which model/environment produced a roadmap claim. They may be archived under a
  deliberate evidence-retention policy, but should not be blindly deleted.
- `studio/next/assets/*` are generated frontend output with content hashes. Rebuilds replace
  old hashes; review tracked deletions/new assets as one build-output change.
- Files under the user’s `~/.clozn` tree are runtime state, model artifacts, pins, and local
  registries outside this source checkout. Never clean that tree as repository hygiene.
