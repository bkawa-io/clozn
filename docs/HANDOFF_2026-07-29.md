## 2. What these waves implemented

### Exact execution fork and checkpoint foundation

Implemented:

- Private worker protocol 1.1 with process-generation-scoped checkpoint IDs.
- Central checkpoint issuance, lookup, true FIFO eviction, and optional generation preconditions.
- Public schemas:
  - `clozn.checkpoint-reference.v1`
  - `clozn.execution-fork.v1`
- Gateway paths:
  - `POST /runs/<id>/execution-fork/checkpoint`
  - `POST /runs/<id>/execution-fork/plan`
  - `POST /runs/<id>/execution-fork`
  - `GET /execution-forks/<id>`
- Exact-fork planning that returns one honest outcome:
  - `exact_execution_fork`
  - `reconstructed_replay`
  - `unavailable`
- Recorded-parent checkpoint capture using the identity-matched worker:
  - prompt IDs are reconstructed through `/score`
  - recorded continuation IDs remain separate across the BPE boundary
  - the original prompt boundary is preserved
  - fixed-seed sampler provenance is restored
  - steering is eligible only when the recorded raw vector provenance is sufficient
- Mandatory unchanged-control execution before an intervention child is accepted.
- Immutable terminal receipts and successful child-run lineage.
- Runtime/worker identity checks before execution, including restart-safe generation identity.
- Exact-fork routing consumes the authoritative selected runtime key and worker identity.
- Production-shaped model-free coverage for canonical/friendly IDs, optional adapters, GPU/coarse
  backends, restarts, sampling, steering, and the `EngineSubstrate` path.

Important boundary:

- The legacy `POST /runs/<id>/fork` path and Studio fork action still use reconstructed text-splice
  behavior. They were intentionally not replaced before exact/reconstructed/unavailable parity is
  exposed.
- Checkpoints are still ephemeral worker-memory objects, capped by the worker FIFO. Pinning,
  export/import, truncation, durable inventory, and child-aware deletion do not exist yet.

### Evidence query and stable span foundation

Implemented:

- `clozn.run-investigation.v1`.
- Read-only `GET /runs/<id>/investigation`.
- `clozn.text-span-addresses.v1`.
- Metadata-only `GET /runs/<id>/span-addresses`.
- Stable half-open Unicode code-point addresses and SHA-256 basis/span hashes for delivered messages,
  rendered-prompt segments, source spans, answer spans, and claims.
- Explicit full, metadata-only, redacted, unavailable, failed, and drifted resolution states.
- Existing persisted context, influence, diagnosis, comparison, and corrective availability are
  projected without starting new model work or rewriting runs.
- Redaction wins over stale duplicated text, and malformed private artifacts do not leak exception
  details.

Important boundary:

- A fully normalized cross-artifact evidence vocabulary is not complete. Existing artifact-specific
  closed unions remain intact, which preserves their current safety invariants.
- No universal numeric "importance" score was introduced.

### "What did the model receive?" Studio surface

- Distinct presentations for delivered, assembled, omitted, redacted, unavailable, and failed data.

- Abort/stale-response protection when switching runs.
- A real Vitest, React Testing Library, and jsdom component-test harness.
- Canonical Scope URL state for view, token, reference run, and layer, with restoration and

Important boundary:

  in the React Studio.

### Managed preloaded multi-model runtime

Implemented:

- ADR and schema for the versioned model-routing contract.
- `clozn.managed-models.v1` configuration, schema registration, and fixtures.
- Reusable worker handle and registry keyed by exact runtime identity.
- Independent private-loopback worker start, handshake, health, restart, failure recovery, and stop.
- `clozn serve --models-config`, with default/preload/resident-limit overrides while preserving
  `clozn serve MODEL`.
- Multiple preloaded workers under one gateway supervisor.
- Atomic private supervisor-to-gateway routing projection.
- File-backed gateway router and request-scoped selection for native, OpenAI, and Ollama paths.
- Authoritative routing receipts containing selected runtime and worker identity.
- Configured/resident lifecycle reporting and privacy-safe managed health output.
- Nested PID shutdown and liveness-based `clozn ps` behavior for degraded managed gateways.
- Environment isolation between managed and legacy launches.
- Executable-digest identity for legacy serving, with one engine discovery reused across restarts.
- Retryable transient routed-worker health failures.
- Managed run-scoped engine operations fail closed when the parent model is not explicitly selected;
  they no longer risk silently analyzing a run with the default worker.

Important boundary:

- This is a preloaded runtime only. Cold loading, load coalescing, eviction, bounded parallel
  generation, queueing, and worker-request cancellation are not implemented.
- The existing global state-changing gate remains.
- Receipt/replay/influence/legacy-fork paths that lack explicit parent-model selection intentionally
  return unavailable in managed mode. Exact execution fork has explicit selection.
- Managed SAE/J-lens configurations fail closed because their value-bearing artifact identities are
  not represented by the v1 runtime key.
- User documentation still needs a copyable managed-model manifest and qualification/serve example.

### Mechanistic correctness and supporting foundations

Implemented:

- Causal-bisect random controls now derive an order-independent per-site uint64 seed from the base
  seed. Leaves no longer share one frozen random direction.
- The artifact records the seed-derivation strategy and each transplant still records its actual
  seed.
- The Studio component harness and URL-state work remove two prerequisites that previously blocked
  the workbench.

Not implemented:

- Mechanistic CLI or HTTP product surfaces.
- Resolution from a failed experiment cell or changed diff token into a mechanistic target.
- Mixed FFN-plus-head joint windows.
- Broader head-search coverage.

## 7. Known limits and research debt

- Exact checkpoints are ephemeral and FIFO-limited until `FORK-PIN-01`.
- Exact capture requires sufficient original identity, trace, prompt boundary, sampler, and supported
  intervention provenance. Unsupported structured/reasoning/guard cases fail closed.
- Cooperative cancellation cannot interrupt an already in-flight private worker call because the
  worker protocol has no request ID for it.
- Managed-mode older run analysis paths fail closed until they can select by the parent run's model.
- The preloaded registry does not yet imply an Open WebUI replacement; live compatibility
  qualification and dynamic model lifecycle are still required.
- Head-search results remain coverage-bounded because the observational top-16 selection favored late
  layers.
- Mixed FFN-plus-head windows require a per-site hook list and must preserve the rule that later
  residual writes can erase earlier additive contributions.
- Depth and raw logit leverage are not fully separated.
- The mixed-precision "protect late MLP precision" experiment remains the highest-value externally
  checkable research follow-up.
- The 30-case population sample was category-stratified, not random over all disagreements.
