### 7. Self-serve qualification is a separate program

The product intentionally remains Torch/Transformers-free. Qualification may use a
heavier lab environment and must install only validated, checksummed artifacts. Q1–Q8
remain the broad qualification program: manifest/lifecycle, planner, core runner, dial
calibration, J-lens adapter, wave batteries, transactional artifact install/rollback,
and one end-to-end acceptance fixture. Keep product-only checks separate from lab-only
steps and never equate a successful fit with semantic usefulness.

Q1/Q2 now has a model-free product seam: `clozn qualify MODEL --plan` emits the versioned
`clozn.qualification-plan.v1` artifact. It reads only GGUF header metadata, estimates disk/VRAM/RAM
needs, reports optional lab dependency presence, and marks every planned step as product- or lab-bound.
It always says `not_qualified`; it does not load a worker, run a battery, install an artifact, or
import Torch/Transformers. Q3-Q8 now have stdlib-only orchestration seams. `clozn qualify MODEL --run`
performs the opt-in Q3 core smoke, verifies a Context Receipt, records exact GGUF identity and gateway
wall-clock timing, and emits `clozn.qualification-run.v1` without claiming full qualification. Q4/Q5
