# Clozn Studio Design Implementation Roadmap

## Phase A — Foundation

Visual grammar, tokens, layout, visualization guide, and motion specification.

## Phase B — Shell

Desktop workspace, rail, toolbar, inspector, timeline, responsive collapse, and command-palette scaffold.

## Phase C — Observatory

Hero-first layout, optical scaffold, selection inspector, replay timeline, selected-token bloom, and explicit illustrative disclosure.

## Phase D — Lens

Reading-first proportions, docked controls, synchronized evidence selection, stronger honesty drawer, and long-response ergonomics.

## Phase E — Compare and Behavior

Shared divergence grammar, symmetric run identity, intervention stitching, consequence inspector, and causal uncertainty disclosure.

## Phase F — Polish

Keyboard shortcuts, saved layouts, resizing, accessibility, animation profiling, performance, and empty/error states.
