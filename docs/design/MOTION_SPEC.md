# Clozn Studio Motion Specification

- State transition: 140–220ms
- Spatial transition: 220–420ms
- Computational event: recorded/simulated event timing
- Ambient: 2.8–8s, low amplitude

Rules:

1. Idle instruments remain stable.
2. Ambient motion never crosses text or controls.
3. Selection settles; it does not pulse forever.
4. Repeated events remain distinguishable at high speed.
5. Reduced motion preserves final state and event order without travel or flicker.
